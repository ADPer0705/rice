> [!NOTE]
> These keymaps are meant to be implemented with ADPer's keyboard
> These will be implemented both at the OS level and if possible in the keyboard's firmware

# Keymaps
long press A --> @
long press - --> long dash

### Navigation
ctrl + k -> up
       h -> left
       j -> down
       l -> right
       w -> next word
       W -> previous word

# Replacements
->  will give short arrow
--> will give long arrow
